## Sobre este template

Página pessoal/portfólio de página única, **sem etapa de build**, hospedada no GitHub Pages.
Desenvolvida com foco em performance, acessibilidade e boas práticas atuais:

- 🌗 **Tema claro/escuro** — automático (preferência do sistema) + botão manual, persistido em `localStorage`
- 🌐 **Bilíngue PT-BR / EN** — alternância instantânea sem recarregar a página
- ⚡ **HTML + CSS puro** — sem frameworks nem JavaScript pesado; `.nojekyll` evita o processamento Jekyll
- ♿ **Acessível** — HTML semântico, skip-link, foco visível, `prefers-reduced-motion`
- 🔎 **SEO/Social** — Open Graph, Twitter Card e dados estruturados JSON-LD (`schema.org/Person`)
- 📱 **Responsivo** — layout fluido com `clamp()` e grid

## Estrutura

```
.
├── index.html          # conteúdo e marcação semântica
├── assets/style.css    # design system (tokens, temas, componentes)
├── .nojekyll           # desativa o Jekyll
└── README.md
```

## Como personalizar

1. Edite os textos diretamente em `index.html` (blocos `.pt` e `.en` para cada idioma).
2. Ajuste cores e espaçamentos nas variáveis CSS em `:root` / `:root[data-theme="light"]`.
3. Adicione sua foto em `assets/avatar.jpg` (sem ela, exibe o monograma **BM**).
